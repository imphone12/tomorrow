# Tomorrow

A 3D Vice City-inspired browser game prototype built in the browser with Three.js.

## Run locally

From the repo root:

python3 start_server.py

Then open:

http://localhost:8000/index.html

Do not open the game files directly as a file:// URL. The 3D modules and browser features work correctly only when served through a local web server.

## Controls

- WASD / Arrow keys: move
- Shift: sprint
- E: enter / exit car
- F: interact
- Space: shoot
- Q: cycle weapon
- Enter: cheat console
